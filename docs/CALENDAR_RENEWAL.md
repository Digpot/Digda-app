# 디그팟 · 일정 캘린더(Calendar) 리뉴얼 제안

> 대상 화면: **일정 탭 — 월간 캘린더 + 오늘의 일정**
> 선정 이유: 그룹 다이어리·일정이 앱의 두 축인데, 캘린더는 마케팅용 월 그리드 수준에 머물러 있어 **일일 사용성에서 가장 큰 격차**를 보임.
> 캔버스 참고: `index.html` → “일정 캘린더 리뉴얼” 섹션 (진단 / Before / After)

## 2. 현재 화면 진단

| # | 문제 | 분석 | 기대 개선 효과 |
|---|------|------|----------------|
| 01 | **뷰 모드 부재** | 월간 그리드만 존재. 시간대별(일)·주간 뷰가 없어 바쁜 날 일정 파악 어려움. | 월/주/일 전환으로 상황별 최적 뷰 제공 |
| 02 | **이벤트 정보 빈약** | 날짜 칸에 작은 pill 1개 = 일정 1개만. 시간·장소·참석자 모름. | 다중 이벤트 도트 + 상세 타임라인으로 정보량 ↑ |
| 03 | **작성자/참석자 부재** | 그룹 앱인데 누구 일정인지 표시 없음, 멤버 필터 불가. | 아바타 표시 + 멤버 필터로 “우리” 맥락 강화 |
| 04 | **추가 진입점 없음** | 일정 생성 버튼이 없어 추가 방법 불명확. | FAB 제공 → 일정 생성 전환율 ↑ |
| 05 | **오늘 강조 약함** | 검정 원 표시뿐, “오늘로 이동” 단축 없음. | coral 강조 + ‘오늘’ 칩 → 주목도·복귀 동선 ↑ |
| 06 | **시간 표현 단조** | “오늘의 일정”이 점+텍스트만. 순서·소요시간 안 드러남. | 시간 레일 타임라인으로 하루 흐름 직관화 |

## 3. 개선 방향 (설계 원칙)

1. **“달력”에서 “일정 관리”로** — 날짜만 보여주는 달력이 아니라, 일정을 읽고/추가하고/필터하는 도구.
2. **상황별 뷰** — 월(전체 조망) / 주(이번 주 집중) / 일(시간대별).
3. **그룹다움** — 모든 일정에 작성자·참석자 아바타, 멤버별 필터.
4. **접근성·일관성** — 브랜드 coral 강조, 대비 AA, 터치 타깃 ≥ 48pt.

## 4. 개선된 화면 구성 (위 → 아래)

### ① 헤더
- `일정` 타이틀 + 우측 **검색** / **알림(도트)** 아이콘 버튼
- 이유: 일정이 쌓이면 검색이 필수, 알림 진입점 일관 배치.

### ② 월 네비게이션 + ‘오늘’ 칩
- `‹ 2026년 6월 ›` + 우측 `오늘` 칩(coral)
- 이유: 다른 달 탐색 후 한 번에 복귀(문제 05).

### ③ 뷰 토글 (Segmented)
- `월 / 주 / 일` 세그먼트 컨트롤(현재 ‘월’ 활성)
- 이유: 문제 01 해결. 상황에 맞는 밀도 선택.

### ④ 멤버 필터
- 멤버 아바타 스택 + `전체 ▾`
- 이유: 문제 03 해결. “엄마 일정만” 같은 필터링.

### ⑤ 월간 그리드
- 오늘 = coral 라운드 스퀘어 강조
- 날짜 아래 **다중 이벤트 도트**(최대 3개, 색=카테고리/멤버)
- 일/토 색상 구분 유지(빨강/파랑)
- 이유: 문제 02·05 해결.

### ⑥ 선택일 타임라인
- `6월 1일 월요일` + `일정 N개`
- **좌측 시간 레일 + 우측 이벤트 카드**(좌측 컬러 바 + 제목 + 장소/그룹 + 참석자 아바타)
- 종일 일정은 상단, 시간 일정은 시간순
- 이유: 문제 02·06 해결. 하루 흐름을 한눈에.

### ⑦ FAB
- 우하단 coral `+` → 일정 추가 (롱프레스: 빠른 카테고리 선택)
- 이유: 문제 04 해결.

### ⑧ 하단 탭바 — 일정 활성(유지)

## 7. 접근성 체크리스트 (WCAG 2.1 AA)

- [ ] 이벤트 색 도트는 색 + 위치 + (탭 시) 텍스트로 의미 전달 (색맹 대응)
- [ ] 오늘/선택일 상태를 색만이 아닌 굵기·배경·`aria-current="date"`로 구분
- [ ] 날짜 셀 터치 타깃 ≥ 44×44pt, 그리드 셀 높이 충분히 확보
- [ ] 요일 색(일=빨강/토=파랑) 대비 ≥ 4.5:1 (현 `#EF4444`/`#60A5FA` 확인, 필요 시 톤 보정)
- [ ] VoiceOver: 날짜 `“6월 1일 월요일, 일정 2개”` 식 합성 라벨
- [ ] 뷰 토글은 `role="tablist"`, 멤버 필터는 토글 상태 라벨 제공
- [ ] `prefers-reduced-motion` 시 월 전환 슬라이드 애니메이션 축소

## 8. 추가 기능 제안 (우선순위)

| 우선 | 기능 | 설명 |
|------|------|------|
| P0 | **일/주 뷰 구현** | 일 뷰=시간 레일 24h, 주 뷰=7일 컬럼 |
| P0 | **일정 상세/편집 시트** | 이벤트 탭 → 상세(제목·시간·장소·참석자·메모·댓글) |
| P1 | **반복 일정** | 매주/매월/매년(기념일) + 종료 조건 |
| P1 | **일정 ↔ 일기 연동** | 지난 일정에서 “이 날 일기 쓰기” 바로가기 |
| P1 | **기념일 자동화** | 생일·기념일 등록 시 매년 자동 + D-day 표시 |
| P2 | **알림 커스터마이즈** | 일정 N분/시간/일 전, 멤버별 on/off |
| P2 | **공유/내보내기** | 시스템 캘린더(iCal) 연동, 일정 이미지 공유 |

## 9. 구현 시 고려사항

### 데이터
```ts
interface CalendarEvent {
  id: string;
  groupId: string;
  title: string;
  start: string;          // ISO
  end?: string;
  allDay: boolean;
  place?: string;
  color: string;          // 카테고리/멤버 색
  authorId: string;
  attendees: string[];    // userId[]
  repeat?: { freq: 'weekly'|'monthly'|'yearly'; until?: string };
  reminders?: number[];   // 분 단위 (예: [60, 1440])
}
interface CalendarViewState {
  mode: 'month' | 'week' | 'day';
  focusedDate: string;
  memberFilter: string[]; // 빈 배열 = 전체
}
```

### 상태/성능
- 월 단위로 이벤트 prefetch(직전/다음 달 포함) → 스와이프 전환 즉시 렌더.
- 멤버 필터·검색은 클라이언트 필터(이미 로드된 월 범위 내) 우선.
- 반복 일정은 클라이언트에서 해당 월 인스턴스로 전개(서버는 룰만 저장).

### 레이아웃
- 월 그리드는 6주(42칸) 고정 높이로 전환 시 점프 방지.
- 시간 레일은 표시되는 일정의 min~max 시간 기준으로 압축(빈 새벽 시간 접기).
- Safe-area + FAB는 탭바 위 16~24pt.

### 엣지 케이스
- 하루 일정 4개+ → 도트 3개 + “+N”, 타임라인은 전체 노출.
- 종일 + 시간 일정 혼재 → 종일 상단 그룹핑.
- 자정 넘는 일정 / 여러 날 일정(bar) 처리.
- 일정 0개 날 → “이 날은 비어 있어요 · 일정 추가” placeholder.

### 계측
- `calendar_view_change`(mode), `calendar_date_select`, `calendar_event_open`, `calendar_member_filter`, `calendar_fab_tap`, `calendar_today_tap`.
- 효과 측정: 일정 생성 전환율, 평균 뷰 전환 횟수, 일정 상세 진입율.

## 10. 단계별 적용 로드맵

1. **Phase 1** — 헤더/월 네비/‘오늘’ 칩 + 다중 이벤트 도트 + 타임라인 카드(아바타 포함)
2. **Phase 2** — 뷰 토글(주/일) + FAB + 일정 상세/편집 시트
3. **Phase 3** — 멤버 필터 + 검색 + 반복 일정 + 알림 커스터마이즈
4. **Phase 4** — 일기 연동 · 기념일 자동화 · iCal 공유
