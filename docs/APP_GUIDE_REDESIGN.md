# 디그팟 · 앱 사용가이드(5페이지) UI/UX 개선안

> 대상 화면: **마이페이지(MY) → “앱 사용가이드”** 버튼으로 열리는 **5페이지 스와이프 가이드**
> 목적: 글만 빽빽한 5페이지를 *모찌·일러스트가 있는 친절한 온보딩형 5페이지*로 개선 (가독성 · 흐름 · 브랜드 정서 · 가치 전달)
> 캔버스 참고: `index.html` → “앱 사용가이드 개선” 섹션 (UX 진단 / Before / 01~05)
> 구현 파일: `screen-guide.jsx` (`Guide1`~`Guide5`, `CurrentGuide`, `GuideAnalysis`)

---

## 1. 현재(Before) 진단

마이페이지에서 “앱 사용가이드”를 누르면 나오는 5페이지가 **텍스트 위주**라, 처음 사용자가 따라 하기 어렵고 디그팟 특유의 정서가 없습니다.

| # | 문제 | 분석 |
|---|------|------|
| 01 | **텍스트 과다** | 페이지 내내 글만 빽빽. 이미지·예시 화면이 없어 따라 하기 어려움. |
| 02 | **흐름이 안 보임** | “그룹→초대→일기→일정→모찌” 순서가 페이지로 드러나지 않음. 진행 위치(몇/5)도 모호. |
| 03 | **브랜드 정서 없음** | 모찌 캐릭터·코랄 톤이 없어 무미건조. 앱의 따뜻한 톤과 단절. |
| 04 | **가치 미전달** | “어떻게”만 있고 “왜 좋은지”가 빠짐. 끝까지 볼 동기와 시작 CTA가 약함. |

---

## 2. 개선 방향

1. **읽는 가이드 → 보는 가이드** — 페이지마다 *일러스트 1개 + 한 문장 가치*.
2. **5페이지 = 5단계 흐름** — 환영 → 그룹·초대 → 그림일기 → 일정 → 모찌.
3. **디그팟다움** — 모찌 마스코트 + 페이지별 소프트 컬러(coral/blue/green/yellow/purple).
4. **진행감 + 출구** — 하단 **페이지 인디케이터** + `다음`, 마지막은 `디그팟 시작하기`. 상단 `건너뛰기`.

---

## 3. 페이지 공통 레이아웃 (`GuidePage`)

```
┌─────────────────────────────┐
│  ‹                  건너뛰기 │  Top bar (마지막 페이지는 건너뛰기 없음)
│ ╭─────────────────────────╮ │
│ │      일러스트(소프트)    │ │  Illustration (페이지별 accentBg)
│ │     모찌 / 카드 / 칩     │ │
│ ╰─────────────────────────╯ │
│ STEP n                       │  eyebrow (accent 컬러)
│ 큰 제목                       │  title 38/800
│ 한두 줄 설명                  │  body 21/500
│                              │
│ ●━●  ○  ○  ○                 │  page dots (active = accent 와이드)
│ [        다음  ›        ]    │  CTA (accent filled)
└─────────────────────────────┘
```

- props: `n, total=5, accent, accentBg, illo, eyebrow, title, body, cta`
- 제목/본문 `word-break: keep-all` (한글 줄바꿈 안정).

## 4. 5개 페이지 구성

| # | accent | eyebrow | 제목 | 핵심 메시지 | 일러스트 |
|---|--------|---------|------|-------------|----------|
| **01** | coral | WELCOME 🌷 | 함께 쓰는 그림일기, 디그팟 | 친구·연인·가족과 일정·추억을 한 권에 | 모찌 + 일기/하트/캘린더 버블 |
| **02** | blue | STEP 1 | 그룹을 만들고 초대해요 | 초대코드 하나로 손쉽게 합류 | 초대코드 카드(`A8K-2F9`) + 멤버/추가 버블 |
| **03** | green | STEP 2 | 그림일기를 함께 남겨요 | 그림·글로 기록하고 댓글로 마음 나눔 | 일기 카드(사진 placeholder) + 펜/댓글 버블 |
| **04** | yellow | STEP 3 | 일정을 함께 관리해요 | 모임·기념일을 한 캘린더에 | 미니 캘린더(날짜 강조 + 일정 칩) |
| **05** | purple | STEP 4 | 퀴즈 풀고 모찌를 키워요 | 함께 퀴즈 풀면 그룹 모찌가 성장 | 모찌(레벨업 ✨) + 퀴즈/Lv 카드 |

- **05 CTA** = `디그팟 시작하기` (가이드 종료 → 홈/온보딩 완료 처리).
- 일러스트의 카드·버블·placeholder는 **실제 브랜드 일러스트로 교체 권장**(현재는 시안용 단순 도형).

## 5. Before / After 요약

| 영역 | Before | After |
|------|--------|-------|
| 형식 | 텍스트 5페이지 | 일러스트 + 한 문장 5페이지 |
| 흐름 | 순서 불명확 | 5단계(환영→…→모찌) 명시 |
| 진행 위치 | 없음 | 페이지 인디케이터(●━●○○○) |
| 브랜드 | 무채색 | 모찌 + 페이지별 소프트 컬러 |
| 가치 | “어떻게” | 기능별 “왜 좋은지” 한 줄 |
| 종료 | 모호 | `디그팟 시작하기` CTA |

## 6. 접근성 (WCAG 2.1 AA)

- [ ] 페이지 전환은 스와이프 + **인디케이터 탭/좌우 버튼** 동시 지원.
- [ ] 인디케이터 `aria-label="3/5 페이지"`, 캐러셀 `role="group"`.
- [ ] 일러스트는 `aria-hidden`(장식). 의미는 제목/본문 텍스트로 전달.
- [ ] 본문 대비 ≥ 4.5:1. 소프트 배경 위 텍스트는 ink/ink2.
- [ ] 터치 타깃(CTA·건너뛰기·인디케이터) ≥ 48pt.
- [ ] `prefers-reduced-motion` 시 페이지 전환·✨ 모션 최소화.

## 7. 구현 메모

```ts
interface GuidePageData {
  n: number; total: 5;
  accent: string; accentBg: string;     // 페이지별 컬러
  eyebrow: string; title: string; body: string;
  illo: 'welcome' | 'invite' | 'diary' | 'calendar' | 'mochi';
  cta?: string;                          // 마지막 페이지만 커스텀
}
```

- 가이드는 **정적 콘텐츠** → 번들 동봉(오프라인 노출 가능), i18n 키 분리.
- 진입점: **MY/설정 → 앱 사용가이드** (요청 화면). 추가로 온보딩 마지막·빈 상태에서도 재사용 가능.
- “다시 보지 않기”/마지막 본 페이지는 로컬 저장.
- 색상·radius·타이포 기존 브랜드 토큰(`#FF6B6B`, Pretendard, radius 22~34).

### 계측(Analytics)
- `guide_open`(source=mypage), `guide_page_view`(n), `guide_skip`(n),
  `guide_complete`, `guide_start_cta`.
- 지표: 페이지별 이탈, 완독률, 가이드 후 첫 그룹/첫 일기 작성 전환.
