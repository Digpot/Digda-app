# 디그팟 · 그림일기 캘린더(Diary Calendar) 신규 화면 제안

> 대상: **일기 탭 — 그림일기 진입 화면**
> 변경: 최신순 리스트 → **사진·기분으로 채워진 “추억 달력”** + 리스트 토글
> 캔버스 참고: `index.html` → “그림일기 캘린더” 섹션 (진단 / Before / After)

---

## 1. 배경 — 왜 캘린더 뷰인가

현재 일기 탭은 일기를 **최신순 카드 리스트**로만 보여줍니다. 일기가 쌓일수록 다음 문제가 생깁니다.

| # | 문제 | 분석 | 기대 효과 |
|---|------|------|-----------|
| 01 | **시간 축 탐색 불가** | 특정 날짜·과거 추억을 찾으려면 끝없이 스크롤. | 달력에서 날짜로 바로 점프 |
| 02 | **기록 동기 부족** | 얼마나 꾸준히 썼는지, 빈 날이 며칠인지 안 보임. | 연속 기록·빈 날 시각화로 “계속 쓰고 싶게” |
| 03 | **한눈 조망 부재** | 한 달 추억을 사진 모자이크로 훑어볼 방법 없음. | 회고·돌아보기 경험 제공 |
| 04 | **기분 데이터 미활용** | 일기마다 기분을 기록하는데 모아 보여주지 않음. | 정서 회고(무드 트래킹) |

> 핵심 통찰: **일기는 “날짜에 묶인 추억”** 이므로, 달력은 리스트보다 자연스러운 1차 뷰입니다. 리스트는 보조 뷰로 토글 제공.

---

## 2. 설계 원칙

1. **사진이 곧 날짜** — 빈 칸 대신 그날의 대표 사진 썸네일로 달력을 채워 “추억 모자이크”를 만든다.
2. **습관을 보이게** — 연속 기록·이번 달 편수·기분 통계로 기록 동기를 부여.
3. **오늘로 유도** — 빈 오늘 칸은 `+`로, 하단 프롬프트 카드로 작성을 자연스럽게 권유.
4. **브랜드·접근성 일관** — coral 강조, 대비 AA, 터치 타깃 ≥ 48pt.

## 3. 화면 구성 (위 → 아래)

### ① 헤더
- `그림일기` 타이틀 + 우측 **뷰 토글**(캘린더 / 리스트 세그먼트, 캘린더 활성)
- 이유: 캘린더를 기본으로, 리스트를 보조로.

### ② 월 네비게이션
- `‹ 2026년 6월 ›` — 좌우 스와이프/탭으로 월 이동

### ③ 통계 스트립 (일기 전용)
- `이번 달 일기 N편` (coral) · `연속 기록 🔥 N일` (amber) · `가장 많은 기분 😊` (purple)
- 이유: 문제 02·04 해결. 기록 습관과 정서를 요약.

### ④ 사진 캘린더 그리드
- 일/토 요일 색 구분
- **일기 있는 날** = 사진 썸네일 타일 + 하단 그라데이션 + 모서리 기분 이모지
- **일기 없는 날** = 옅은 surface 빈 타일
- **오늘(빈 날)** = coral 점선 + `+` (작성 유도), 오늘(작성됨) = coral 보더
- 이유: 문제 01·03 해결. 날짜로 탐색 + 추억 한눈에.

### ⑤ 오늘의 기록 프롬프트
- coral 그라데이션 카드: `✏️ 오늘은 어떤 하루였나요?` + `지금 기록하면 연속 6일째 🔥`
- 이유: 작성 전환 + 연속 기록 유지 동기.

### ⑥ FAB
- 우하단 coral `+` → 새 일기 작성 (오늘 날짜 프리셋)

### ⑦ 하단 탭바 — 일기 활성

## 5. Before → After

| 영역 | Before | After |
|------|--------|-------|
| 1차 뷰 | 최신순 리스트 | 사진 캘린더 (리스트 토글) |
| 날짜 탐색 | 스크롤 | 달력에서 직접 점프 |
| 기록 습관 | 안 보임 | 연속 기록·편수 통계 |
| 기분 | 일기 안에만 | 통계로 회고 |
| 조망 | 카드 단위 | 한 달 사진 모자이크 |
| 작성 유도 | 없음 | 프롬프트 카드 + FAB |

## 6. 접근성 체크리스트 (WCAG 2.1 AA)

- [ ] 사진 타일 위 기분 이모지는 장식이 아닌 의미 → VoiceOver `“6월 8일, 행복, 일기 있음”`
- [ ] 사진 위 텍스트/아이콘이 없으므로 썸네일 자체에 대비 의존 안 함(하단 그라데이션은 보조)
- [ ] 빈 날 vs 작성일 구분을 색만이 아닌 채움 유무·보더로 구분
- [ ] 날짜 타일 터치 타깃 ≥ 44×44pt
- [ ] 통계 카드 의미 라벨(`“이번 달 일기 13편”`)
- [ ] 뷰 토글 `role="tablist"`, 선택 상태 노출
- [ ] `prefers-reduced-motion` 시 월 전환·타일 페이드 최소화

## 8. 구현 시 고려사항

### 데이터
```ts
interface DiaryEntry {
  id: string;
  groupId: string;
  date: string;        // YYYY-MM-DD (날짜에 1차 매핑)
  title: string;
  thumbnailUrl?: string;
  mood: string;        // emoji or enum
  authorId: string;
}
interface DiaryCalendarMonth {
  month: string;       // YYYY-MM
  entriesByDay: Record<number, DiaryEntry[]>;
  stats: { count: number; streak: number; topMood: string };
}
```

### 상태/성능
- 월 단위 prefetch + 인접 월 캐시 → 스와이프 즉시 전환.
- 썸네일은 저해상도 우선 로드(blur-up), 셀 크기에 맞춘 리사이즈 이미지 사용.
- 통계(편수·연속·최다 기분)는 서버 집계 우선, 없으면 클라이언트 계산.

### 레이아웃
- 그리드 6주 고정 높이(전환 점프 방지). 타일 `aspect-ratio` 고정.
- 하루 여러 편 → 대표 1장 + 우상단 `+N` 뱃지.
- Safe-area + FAB는 탭바 위 16~24pt.

### 엣지 케이스
- 이번 달 일기 0편 → 빈 상태 일러스트 + “첫 일기 쓰기” CTA, 통계는 0/0.
- 미래 날짜 타일은 비활성(작성 불가).
- 사진 없는 일기(글만) → 썸네일 자리에 기분 이모지 큰 버전 + 단색 배경.
- 연속 기록 끊김 표시(오늘 안 쓰면 streak 위험 힌트).

### 계측
- `diary_view_toggle`(calendar/list), `diary_day_open`, `diary_month_change`, `diary_prompt_tap`, `diary_fab_tap`, `diary_streak_milestone`.
- 효과 측정: 일기 작성 전환율, 연속 기록 평균 길이, 과거 일기 재방문율.

## 9. 단계별 적용 로드맵

1. **Phase 1** — 사진 캘린더 그리드 + 통계 스트립 + 오늘 프롬프트 + FAB
2. **Phase 2** — 리스트 토글 + 날짜→상세 연결 + 빈 상태
3. **Phase 3** — 무드 트래커 + 연속 기록 리워드(모찌 연동) + 회고 카드
4. **Phase 4** — 멤버 필터 · 검색 · 콜라주 공유
