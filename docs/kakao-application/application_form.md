# 신청 사유 및 활용 시나리오

> 카카오 디벨로퍼스 신청서의 "신청 사유 및 활용 시나리오" 입력란에 그대로 복붙해서 사용하세요.

---

## 1. 신청 사유 (요약)

태리팟이 운영하는 그룹 다이어리 앱 **"디그팟"**의 그림일기 작성 기능에서, 사용자가 그날 다녀온
장소(카페·식당·관광지 등)를 일기에 함께 기록할 수 있도록 **카카오 로컬(장소) 검색 API** 사용 권한을
신청합니다. 사용자가 입력한 키워드로 장소를 검색해 정확한 상호명을 선택·저장하기 위한 용도이며,
이를 위해 키워드 검색 API(`GET /v2/local/search/keyword.json`) 호출 권한이 필요합니다.

- **신청 API**: 카카오 로컬 — 키워드로 장소 검색 (`/v2/local/search/keyword.json`)
- **사용 방식**: REST 호출(`Authorization: KakaoAK <REST_API_KEY>`), 카카오맵 JavaScript SDK·지도 임베드는 사용하지 않음
- **호출 주체**: 서비스 명의 REST 키로 호출 (사용자 카카오 로그인과 무관)

## 2. 서비스 개요

- **서비스명**: 디그팟(DigPot) — 그룹 단위 다이어리·일정 공유 모바일 앱 (Android · iOS)
- **운영사**: 태리팟
- **출시 단계**: 베타 운영 중, 정식 출시 준비
- **타겟 사용자**: 가족·연인·친구 등 친밀한 비공개 소그룹

## 3. 카카오 로컬 API 활용 시나리오

### 그림일기 작성 시 "장소 태깅"
사용자가 일기를 작성할 때 그날 다녀온 장소의 **이름을 검색해 본문과 함께 저장**할 수 있도록 지원합니다.
작성 화면의 "장소 추가하기" 영역을 누르면 검색 시트가 열리고, 카카오 로컬 키워드 검색 API를 호출해
결과 목록을 보여준 뒤, 사용자가 선택한 장소의 `place_name`(상호 문자열)을 일기 레코드의 `location`
필드에 저장합니다.

### 호출 흐름 (단계별)
1. 작성 화면에서 "장소 추가하기" 탭 → 검색 시트 열림
2. 사용자가 검색바에 키워드(예: "성수동 카페") 입력 후 **검색 버튼을 누를 때만** API 호출 (자동완성·입력 중 호출 없음)
3. 카카오 로컬 키워드 검색 API가 반환한 상호명·주소 목록을 화면에 표시
4. 사용자가 결과 중 하나를 선택 → 선택한 **장소명(place_name) 문자열만** 자체 서버 DB(`diary.location`)에 저장
5. 좌표(x/y)·전화번호·카카오 내부 ID 등은 저장하지 않음

### 호출 예상 트래픽
- 사용자 1인당 일기 작성 빈도: 주 2~5회
- 일기 작성당 평균 검색 호출: 1~3회
- 베타 단계 MAU 약 500명 → 일일 검색 호출 약 2,000~5,000건
- 정식 출시 후 6개월 시점 MAU 약 5,000명 예상 → 일일 검색 호출 약 20,000~50,000건

## 4. 사용자 가치

장소를 함께 기록함으로써 다음 가치를 제공합니다.
- **기억의 풍부함**: 사진·텍스트·날짜·날씨·기분에 더해 *어디서* 라는 맥락을 한 번에 보존
- **그룹 공유의 의미**: 같은 그룹의 멤버들이 "거기 좋았지" 같은 공감대를 즉시 형성
- **회상 편의**: 추후 캘린더·검색에서 장소별로 추억을 되짚을 수 있는 기반 데이터

## 5. 개인정보·데이터 보호

- 카카오 로컬 API로는 **검색 키워드만** 전달되며, 사용자의 개인정보는 카카오로 전송되지 않습니다.
- 응답 중 사용자가 선택한 장소의 **이름 문자열만** 자체 서버 DB(`diary.location`)에 저장합니다. 좌표·연락처·내부 식별자(id)는 저장하지 않습니다.
- 일기 자체가 비공개(그룹 멤버에게만 공개)이므로 장소 정보도 그룹 외부로 노출되지 않습니다.
- 카카오 REST API 키는 서비스 명의로만 사용되며, 광고·추적 등 다른 목적으로 활용하지 않습니다.

## 6. 호출 화면

별첨 캡처 이미지 참조 — 그림일기 작성 화면에서 "장소 추가하기" 탭 → 검색 시트가 열리고
카카오 로컬 API 결과가 리스트로 표시되어 선택·저장되는 흐름.
(개인정보 보호를 위해 그룹명·작성자명 등 식별 정보는 마스킹 처리)

## 7. 향후 확장 계획

- 검색 결과 선택 시 카카오맵 상세 미리보기 임베드 (카카오맵 JavaScript SDK 도입 검토)
- 일기 캘린더에서 같은 장소로 작성된 일기 모아보기
- 위 두 확장 모두 *현재 신청 범위에는 포함되지 않으며*, 도입 시 별도 신청 또는 변경 신청 예정.
