# 서비스 적용 화면 캡처 가이드

카카오는 **실제 동작 화면 1장**을 요구합니다 (JPG/JPEG/PNG/PDF, 20MB 이내).
와이어프레임/Figma 시안이 아니라 **앱에서 카카오 로컬 API 가 실제로 호출돼 결과가 나오는 화면** 이어야 합니다.

## 권장 캡처 화면

**그림일기 작성 화면 → "장소 추가하기" 시트 → 검색 결과 리스트가 떠 있는 순간**

이 한 장 안에 다음이 모두 보여야 카카오 심사가 빠릅니다.

1. 화면 상단의 검색바에 입력된 검색어 (예: "성수동 카페")
2. 검색 결과 리스트 (장소명 + 도로명/지번 주소)
3. 그 위/아래 디그팟 앱 UI 컨텍스트 (작성 화면임을 알 수 있게)

## 캡처 절차

1. `.env` 에 `KAKAO_REST_API_KEY=55a0a503...` 가 채워져 있는지 확인
2. 앱 fully restart (hot reload X — dotenv 는 부팅 시만 읽음)
3. 그룹 진입 → "그림일기" 탭 → 우측 하단 작성 버튼
4. 메타 영역의 "장소 추가하기" 탭
5. 검색바에 **"성수동 카페"** 입력 → "검색" 또는 엔터
6. 결과 리스트가 뜨면 그 화면을 캡처
   - Android: 전원 + 볼륨 다운 동시 누름
   - iOS: 전원 + 볼륨 업 (또는 홈 + 전원)

## 마스킹 (반드시)

캡처 안에 다음이 보이면 모자이크/검은 박스로 가려야 합니다.

| 항목 | 위치 |
| --- | --- |
| 그룹명 | 작성 화면 상단·헤더 영역에 노출될 수 있음 |
| 사용자 이름 | 디그팟 UI 에는 작성 화면에는 안 나오지만 상태바·알림에 떠 있을 수 있음 |
| 프로필 이미지 | 위와 동일 |
| 디바이스 식별자 | 상단 상태바의 통신사명·시간은 OK, IMEI/UDID 가 보이면 가리기 |
| 카카오 API 키 | 화면에는 절대 노출 안 되지만 디버그 로그 캡처면 마스킹 |

**마스킹 도구 추천**
- 안드로이드: 갤러리에서 사진 편집 → "그리기" 기능으로 검은 박스
- iOS: 마크업 → 사각형 도구
- PC: 그림판, GIMP, [https://www.iloveimg.com/blur-image](https://www.iloveimg.com/blur-image) 같은 웹 도구
