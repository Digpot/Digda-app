서비스 상세 설명

디그팟은 초대 기반의 비공개 그룹 다이어리·일정 공유 모바일 앱입니다. 초대 코드로 가입한 그룹 멤버들이 일정(캘린더), 그림일기, 투두리스트, 캐릭터 키우기 등을 함께 사용하며, 모든 콘텐츠는 그룹 외부로 노출되지 않습니다.

그림일기 작성 화면의 “장소 추가하기” 항목에서, 사용자가 그날 다녀온 카페·식당·관광지의 이름을 검색해 일기 본문과 함께 저장할 수 있도록 카카오 로컬 키워드 검색 API를 활용합니다.

카카오맵 API 활용 시나리오

활용 API — 카카오 로컬 키워드 검색 GET /v2/local/search/keyword.json

  1. 호출 지점 — 그림일기 작성·수정 화면의 “장소 추가하기” 항목을 사용자가 탭하면 검색 시트(bottom sheet)가 열림.
  2. 호출 트리거 — 사용자가 검색바에 키워드(예: “성수동 카페”)를 입력하고 검색 버튼을 누르는 명시적 액션 시에만 호출. 입력 중 자동 호출(autocomplete) 없음.
  3. 응답 활용 — 검색 결과 목록 표시 → 사용자가 선택한 장소의 place_name(문자열)만 diary.location 컬럼에 저장. 좌표·내부 ID·연락처 등은 저장하지 않음.
  4. 호출 방식 — HTTP REST, 헤더 Authorization: KakaoAK <REST_API_KEY>. 카카오맵 JavaScript SDK 및 지도 임베드는 사용하지 않음.

5. 정책 준수 확인 사항

  • 본 계정에는 디그팟 외의 동일 서비스 중복 앱 등록 없음 (도메인 · PackageName · BundleID 기준).
  • 테스트·개발 용도 키는 Test App 가이드를 따라 별도 관리하며, 본 운영 앱과 같은 PackageName 으로 중복 등록하지 않음.
  • 카카오 디벨로퍼스 운영정책 제5조 23항 — 동일 서비스의 다수 계정 운영 금지 — 준수.
  • 카카오맵 API 정책 개편 공지 ①·② 의 변경 사항(쿼터·과금 정책 등)을 인지하고 호출량을 위 트래픽 표 기준으로 모니터링.

6. 요청 사항

위 정보로 디그팟(DigPot) 앱의 카카오맵 / 카카오 로컬 API 호출 권한 심사를 재진행해 주시기 바랍니다. 추가 자료나 보완이 필요할 경우 아래 연락처로 안내 부탁드립니다.
