1. 안내 사항 확인 및 응답 요지

“심사를 신청한 앱 이외, 기존 카카오맵 API 호출 권한을 이미 가진 앱에 대해서도 동일 양식으로 정보를 작성해 주셔야 합니다.” — 가이드 devtalk.kakao.com/t/api/146633

안내해 주신 내용을 확인하였습니다. 본 응답서는 동일 카카오 계정에 등록된 카카오맵 API 권한 보유 앱 2개 전부를, 가이드의 “2. 카카오맵 API 권한 심사 요청 양식”(서비스 상세 설명 / 서비스 주소 / 카카오맵 API 활용 시나리오)에 맞추어 각각 작성한 자료입니다.

1앱-1서비스 정책 준수 선언 — 본 계정의 카카오맵 권한 보유 앱은 붐빔(Boombim)과 디그팟(DigPot) 2개이며, 두 앱은 서로 완전히 다른 서비스입니다(혼잡도 지도 vs 그룹 다이어리). 동일 서비스를 도메인·PackageName·BundleID 기준으로 중복 등록한 사실이 없습니다.
· [앱 1] 붐빔 — 계정 내 먼저 생성되어 카카오맵 API 호출 권한을 이미 보유한 운영 중 서비스(별도 심사 불요).
· [앱 2] 디그팟 — 이번에 신규 생성하여 심사를 요청하는 앱.

① 서비스 상세 설명

붐빔은 카페·식당·헬스장·병원·마트 등 생활 공간의 실시간 혼잡도(붐비는 정도)를 지도 위에서 확인하고 공유하는 위치 기반 모바일 서비스입니다. 사용자의 실시간 참여형 입력과 공공데이터를 결합해 장소별 혼잡도를 산출하고, 이를 지도 위 마커로 시각화합니다. 홈 화면에서는 인근의 한산한 지역과 붐비는 장소 TOP 5 를 제공하며, 만료된 혼잡도 데이터는 회색 마커로 구분 표시합니다. 현재 서울 지역을 중심으로 운영 중입니다.

③ 카카오맵 API 활용 시나리오

  1. 지도 화면 구성 — 앱·웹의 메인 지도 화면을 카카오맵으로 렌더링하고, 그 위에 장소별 혼잡도 마커(붐빔/보통/한산/만료)를 올려 사용자에게 표시합니다.
  2. 좌표 → 행정구역 변환 — 혼잡도 데이터의 위·경도 좌표를 카카오 로컬 좌표→행정구역 코드 변환 (coord2regioncode)으로 행정구역(시/군/구·동)에 매핑해, “인근 지역” 단위의 한산·혼잡 집계와 지역 검색에 사용합니다.
  3. 호출 방식 — 클라이언트는 카카오맵 SDK 로 지도를 표시하고, 좌표 변환은 서버가 카카오 로컬 REST API (Authorization: KakaoAK <KEY>)로 호출합니다.
참고 — 카카오 소셜 로그인(OAuth)도 함께 사용하나, 이는 본 심사 대상인 지도/로컬 API 와는 별개의 인증 기능입니다.

① 서비스 상세 설명

디그팟은 초대 기반의 비공개 그룹 다이어리·일정 공유 모바일 앱입니다. 초대 코드로 가입한 그룹 멤버들이 일정(캘린더), 그림일기, 투두리스트, 캐릭터 키우기 등을 함께 사용하며, 모든 콘텐츠는 그룹 외부로 노출되지 않습니다. 그림일기 작성 화면의 “장소 추가하기”에서 사용자가 그날 다녀온 카페·식당·관광지의 이름을 검색해 일기 본문과 함께 기록할 수 있도록 카카오 로컬 키워드 검색 API를 활용합니다.

③ 카카오맵 API 활용 시나리오

활용 API — 카카오 로컬 키워드 검색 GET /v2/local/search/keyword.json

  1. 호출 지점 — 그림일기 작성·수정 화면의 “장소 추가하기”를 탭하면 검색 시트가 열립니다.
  2. 호출 트리거 — 검색바에 키워드(예: “성수동 카페”)를 입력하고 검색 버튼을 누를 때만 호출. 입력 중 자동 호출(autocomplete) 없음.
  3. 응답 활용 — 결과 목록에서 사용자가 선택한 장소의 place_name(문자열)만 diary.location 컬럼에 저장. 좌표·내부 ID·연락처는 저장하지 않음.
  4. 호출 방식 — HTTP REST, 헤더 Authorization: KakaoAK <REST_API_KEY>. 카카오맵 JavaScript SDK·지도 임베드는 사용하지 않음.

4. 디그팟 서비스 적용 화면 (카카오 로컬 API 호출 화면)

5. 정책 준수 확인 사항

  • 본 계정의 카카오맵 권한 보유 앱은 붐빔(운영)·디그팟(신규) 2개이며, 본 응답서에 두 앱 모두 동일 양식으로 기재함.
  • 붐빔과 디그팟은 서로 다른 서비스로, 동일 서비스를 중복 등록하지 않음 (도메인 · PackageName · BundleID 기준).
  • 이번 심사 요청 대상은 신규 앱 디그팟이며, 붐빔은 계정 첫 앱으로 권한을 자동 보유한 운영 중 서비스임.
  • 테스트·개발 용도 키는 Test App 가이드를 따라 별도 관리하며, 운영 앱과 같은 PackageName 으로 중복 등록하지 않음.
  • 카카오 디벨로퍼스 운영정책(동일 서비스의 다수 계정/중복 등록 금지)을 준수함.
  • 카카오맵 API 정책(쿼터·과금 등) 변경 사항을 인지하고 호출량을 위 트래픽 표 기준으로 모니터링.

6. 요청 사항

위와 같이 계정 내 카카오맵 권한 보유 앱 2개([앱 1] 붐빔 · [앱 2] 디그팟)의 정보를 동일 양식으로 작성하였습니다. 이를 바탕으로 신규 앱 디그팟(DigPot)의 카카오맵 / 카카오 로컬 API 호출 권한 심사를 재진행해 주시기 바랍니다. 추가 자료나 보완이 필요하면 아래 연락처로 안내 부탁드립니다.
